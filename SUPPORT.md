## Reporting Bugs and Feature Requests

- Open a bug report or feature request on [GitHub Issues](https://github.com/avalonreset/legends-stripe/issues).
- Before opening an issue, run `legends-stripe doctor --json` and include the sanitized output along with your Python version and operating system.
- Never include `sk_live_`, `sk_test_`, `rk_`, or `whsec_` tokens, customer emails, or private financial records in public issues.

## Security Issues

Do not report security vulnerabilities in public issues. Follow the private disclosure instructions in [SECURITY.md](SECURITY.md).
