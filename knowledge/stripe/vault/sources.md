# Primary Sources

All operational rules and schema validators in `legends-stripe` are grounded in official Stripe API documentation and RFC standards:

1. **Stripe API Reference (v1 REST, Form-Encoding, and Authentication)**:
   - https://docs.stripe.com/api
   - https://docs.stripe.com/api/authentication
   - https://docs.stripe.com/api/idempotent_requests
2. **Products, Prices, and Lookup Keys**:
   - https://docs.stripe.com/api/products/object
   - https://docs.stripe.com/api/prices/object
   - https://docs.stripe.com/products-prices/manage-prices
3. **Statement Descriptors (5 to 22 ASCII Character Rules)**:
   - https://docs.stripe.com/get-started/account/statement-descriptors
4. **Hosted Checkout Sessions, Customer Portal, and Custom Domains**:
   - https://docs.stripe.com/api/checkout/sessions
   - https://docs.stripe.com/payments/checkout/custom-domains
   - https://docs.stripe.com/customer-management/integrate-customer-portal
5. **Webhooks, HMAC-SHA256 Signatures, and Subscription Lifecycle**:
   - https://docs.stripe.com/webhooks
   - https://docs.stripe.com/webhooks/signatures
   - https://docs.stripe.com/billing/subscriptions/webhooks
6. **Balance, Balance Transactions, Charges, and Payout Reconciliation**:
   - https://docs.stripe.com/api/balance/balance_object
   - https://docs.stripe.com/api/balance_transactions/object
   - https://docs.stripe.com/api/charges/object
   - https://docs.stripe.com/api/payouts/object
7. **Stripe Invoicing, Hosted Invoice Page, and B2B Settlement**:
   - https://docs.stripe.com/invoicing
   - https://docs.stripe.com/api/invoices/object
   - https://docs.stripe.com/api/invoiceitems/object
   - https://docs.stripe.com/invoicing/hosted-invoice-page
